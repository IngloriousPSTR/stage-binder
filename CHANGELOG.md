# Changelog

## 1.0.2 - 2026-08-03

### Changed

- Refreshed public installation and latest-release documentation.
- Replaced deprecated slider tooltip calls while preserving inline values.
- Reworked chord-hover and print CSS to avoid `:has()` and `!important` without changing behavior.
- Added release attestations for `main.js` and `styles.css`.
- Added version consistency checks and regression coverage for Community-review findings.

### Documentation

- Documented the intentional multicolumn layout and deferred the Obsidian 1.13 declarative-settings migration to a focused follow-up.

## 1.0.1 - 2026-07-31

### Added

- Open standalone PDF and image files directly in Performance mode.

## 1.0.0 - 2026-07-25

Initial public release of Stage Binder.

### Added

- ChordPro and Markdown song authoring with chord helpers and guitar diagrams.
- Form-based song arrangements, transposition, Nashville numbers, lyrics-only display, columns, and text sizing.
- Setlist and run-sheet views with songs, prose, PDFs, images, timing, and performance keys.
- Fullscreen performance mode with touch, keyboard, pedal, MIDI, autoscroll, and theme controls.
- Print-note, ChordPro, share-folder, and CCLI report exports.
- A minimal public-domain example set for safe evaluation.

### Privacy

- No telemetry, analytics, accounts, advertising, automatic network requests, or bundled song library.
