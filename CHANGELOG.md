# Changelog

## 1.0.0 - 2026-07-25

Initial public release of ChordPro Studio.

### Added

- ChordPro and Markdown song authoring with chord helpers and guitar diagrams.
- Form-based song arrangements, transposition, Nashville numbers, lyrics-only display, columns, and text sizing.
- Setlist and run-sheet views with songs, prose, PDFs, images, timing, and performance keys.
- Fullscreen performance mode with touch, keyboard, pedal, MIDI, autoscroll, and theme controls.
- Print-note, ChordPro, share-folder, and CCLI report exports.
- A minimal public-domain example set for safe evaluation.

### Privacy

- No telemetry, analytics, accounts, advertising, automatic network requests, or bundled song library.
