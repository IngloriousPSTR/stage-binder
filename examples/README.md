# Public-domain demo set

These files demonstrate ChordPro Studio without distributing licensed music. Copy the `Songs`, `PDF`, and `Setlists` folders into a scratch vault if you want to try them.

- `Amazing Grace.chordpro` uses words by John Newton first printed in *Olney Hymns* in 1779. The Library of Congress documents the publication history: <https://www.loc.gov/collections/amazing-grace/articles-and-essays/timeline/>.
- `Aura Lea.pdf` uses the 1861 song by W. W. Fosdick and George R. Poulton. The Library of Congress dates the work to 1861: <https://www.loc.gov/collections/songs-of-america/articles-and-essays/timeline/1850-to-1899/printable-timeline/>.
- `Public Domain Demo Set.md` links the two examples in a timed run sheet with neutral, invented assignments and transition cards.

The underlying songs are public domain. To the extent that the original formatting and chord placement in these examples is copyrightable, the contributors dedicate it to the public domain under [CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/).

No audio recordings are included.
